# Plan de Negocios - Repostería Funcional & Fitness Uruapan

Proyecto interactivo del plan de negocios para Repostería Funcional y Fitness en Uruapan.

## Contenido
- [`index.html`](index.html): Documento principal interactivo con diseño responsive (Tailwind CSS) y gráficos financieros dinámicos (Chart.js).

## Visualización
Puedes abrir directamente el archivo `index.html` en cualquier navegador web o activar **GitHub Pages** en la configuración del repositorio para consultarlo en línea.
